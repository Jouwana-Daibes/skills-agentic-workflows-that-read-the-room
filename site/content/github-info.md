Recent notable updates (from the GitHub Changelog):

- Dynamic workflows in Copilot CLI and the Copilot app — Copilot now supports dynamic workflows from the CLI and app to help automate and run repeatable developer tasks. Source: https://github.blog/changelog/2026-10-01-dynamic-workflows-in-copilot-cli-and-the-copilot-app
- Stacked pull requests generally available — Organize dependent changes into stacked pull requests to review and merge related work more easily. Source: https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available
- Code coverage uploads no longer fail CI for new branches — Fixes a CI interruption where coverage uploads could fail on newly created branches. Source: https://github.blog/changelog/2026-10-01-code-coverage-uploads-no-longer-fail-ci-for-new-branches
